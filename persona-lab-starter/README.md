# Persona Lab starter

An intentionally rough React starter for the Codex Masterclass exercise.

Participants improve a small simulated-persona journey: select a persona, provide a task, invoke the local demo, and inspect a short evidence trail plus synthetic rationale.

## Run locally

```bash
npm install
npm run dev
```

## Exercise boundaries

- This app has no real browser or model integration.
- The sample journey and rationale are simulated; they are not human research.
- GitHub Pages deployment is intentionally not configured. Creating it is a participant task.
